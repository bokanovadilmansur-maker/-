NEON ARENA - 3D шутер

Как запустить:
1. Распакуй архив (правая кнопка -> Извлечь все). Из самого архива игра не запустится.
2. Открой index.html двойным кликом (Chrome, Edge или Firefox).
3. Нужен интернет: 3D-движок Three.js загружается из сети.

Управление: WASD - движение, мышь - обзор, ЛКМ - огонь, ПКМ - прицел,
R - перезарядка, Shift - бег, Space - прыжок, 1-5 - оружие,
F - сесть в транспорт / выйти, Esc - пауза.
